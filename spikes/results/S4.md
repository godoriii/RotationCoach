## 알게 된 것

1. **한밤 단일 대상 판정에 필요한 항이 매우 적다.** Tip of the Spear 중첩·유무, Raptor Swipe!, Sentinel's Mark, Takedown 쿨다운, Wildfire Bomb `full_recharge_time`, `gcd`, 특성 3개, `howl_summon.ready`가 전부다.
2. **`full_recharge_time`만 진짜 불확실 항이다.** `plst`의 Wildfire Bomb 줄(`full_recharge_time<4+gcd`)과 `sentst`의 줄(`full_recharge_time<4`)에서 쓰인다. 데모 시나리오 2처럼 이 값이 모델 불확실 구간 [3.2, 6.0] s이면 C = {Wildfire Bomb(모델 불확실), Boomstick}이다. 점 추정(중앙값 4.6 s < 4+GCD 5.2 s)으로는 top* = Wildfire Bomb이므로, 실제 행동이 Wildfire Bomb이면 MATCH, Boomstick이면 모델 불확실성 때문에 INDETERMINATE가 된다 (SCORING_SPEC §6.3). → **S2의 Wildfire Bomb 모델 오차가 불확정 비율을 좌우**한다.
3. **집중 조건이 APL에 없다** (TECH_DECISIONS §3.1과 일치). 사용 가능성 검사(`usable`)에서 집중 비용을 직접 확인해야 한다.
4. 3값 평가 데모: 공정성 허용(반응 시간 안의 Raptor Swipe! 발동)과 모델 불확실성(충전 구간)이 후보마다 구분되어 나온다. SCORING_SPEC §6.3 절차가 구현 가능함을 확인.
5. `cds` 목록은 장신구·`this_trinket.*`·`fight_style` 등 판정 제외 항이 대부분이라 MVP에서 제외하는 방침(TECH_DECISIONS §3.3-4)이 맞다.

## 후속 조치

- TECH_DECISIONS §3.3의 "`&`가 `|`보다 강하게 묶이는지 [미확인]" → **[확인]**으로 갱신 (출처 B-17).
