# RISKS — 기술·정책 리스크와 대응

> 상태: 기획 초안 v0.1 (2026-10-16)
> 평가: 가능성 / 영향 = 상·중·하. 출처 번호는 [TECH_DECISIONS 부록 B](TECH_DECISIONS.md#부록-b-출처).

## 요약: 가장 중요한 세 가지

1. **T-1 / P-1 — 전투 중에는 로그가 안 들어올 가능성이 높고, Blizzard는 그런 실시간 이용을 명시적으로 막으려 했다.** → 제품을 "풀 종료 직후 채점"으로 정의했다. 전투 중 갱신은 기본 꺼짐 선택 기능이며 어떤 우회도 하지 않는다.
2. **T-2 — Blizzard가 로그 파일을 더 제한할 수 있다.** → 데이터 소스를 어댑터로 분리하고, 로그를 못 쓰게 되어도 WCL 경로로 사후 분석은 남는다.
3. **T-8 — 숨은 쿨다운 상태(특히 Wildfire Bomb 감소 효과 연쇄)를 잘못 모델링하면 판정 신뢰도가 무너진다.** → 불확실 값 + INDETERMINATE 판정 + S2/S8 검증.
